9-Phase Implementation Protocol — What "New Machine" Actually Means in Practice

When the decision workflow reaches Step 3.0 (new machine), technical implementation follows a documented 9-phase protocol (CLAUDE.md). Each phase has explicit acceptance criteria and a final validation gate (100 Cypher + 162 SPARQL checks). A method is only "done" when all gates pass. This is what compressed months of ad-hoc integration into a repeatable 1–3 day process.

Phase 0 — Pre-implementation
Norm audit (DIN/ISO/ASTM), Kennwerte list, openBIS column check, LSM scope definition
Phases 1–3 — Code
File reader, analysis, fixed-axis plots, Streamlit viewer, auto-sync, dashboard wiring, chatbot RAG
Phases 4–9 — FAIR + KG
FAIR-JSON extractor, data dictionary (norm citations), Neo4j export, Fuseki/SPARQL, QUDT units, PMDco/MaterialDigital ontology crosswalk (6 compliance points)
Abrasion (ASTM G65) was the first new instrument to complete all 9 phases end-to-end — 2 days total for a new machine class. The next method (Erosion, Cavitation, Fretting) starts from the same protocol, not from zero. Adding a method is not a software project — it is a defined, repeatable engineering task.

// Full EHL provenance: Experiment → Lubricant (α) → ResultSet

→ α_Pa_80C = 3.016 × 10⁻⁹ Pa⁻¹ on Lubricant node (α_Pa_40C / 50C / 60C also available) · h_c + λ in ResultSet.output_json

What this graph tells us
One node replaces eight files. Previously, the LSM scan, five rheometer runs, and two IR spectra existed as separate Excel sheets with no machine-readable link to the friction test. The graph makes this connection explicit and queryable.
Full EHL provenance in the graph. Rheo Rotation nodes supply η(T). The Lubricant node (USES_LUBRICANT) carries α = 3.016 × 10⁻⁹ Pa⁻¹ as a direct Neo4j property — sourced from rheo_pressure/pressure-viscosity-coefficient.xlsx and written to the node by export_lubricants(). Both η and α feed the EHL calculation: h_c = 0.039 µm, λ = 1.91 (mixed lubrication). The full chain — measurement → lubricant property → experiment result — is now queryable in one Cypher traversal.
Material nodes are shared. The taC-DLC ball (USES_MATERIAL edge) is the same node used by all other DLC experiments across B3P and GLEX. Any future query for DLC tribological behavior automatically includes SS-P22 — no manual cross-referencing needed.
Before/after IR detects degradation. The two IR-ATR nodes capture lubricant chemistry before and after the friction test. Comparing their spectra reveals whether Glycerol degraded under tribological stress — a cross-method insight invisible in isolated datasets.
Project node = instant portfolio view. The PART_OF_PROJECT edge connects SS-P22 to the SupraSlide node. A single graph query on that project node retrieves all experiments, materials, and analytical data across the entire project — regardless of measurement method.
Sustainability is first-class data. The HAS_SUSTAINABILITY edge links life-cycle assessment data (GWP, PFAS flag, bio-based status) directly to this experiment. SupraSlide's Glycerol bio-lubricant choice can be justified from the graph — not a separate report.

Questions the Graph Can Answer — Right Now

These four SPARQL queries demonstrate the value of a FAIR knowledge graph to colleagues. Each query answers a question that previously required manual Excel lookups across multiple files. Query 4 shows machine-readable derivation chains — unique to TriboCore, required for Nature Scientific Data. Run live in a browser or Jupyter notebook.

1
International Standard Bridge (PMDco)
B3P and GLEX are found with a single international IRI — the graph understands that both are "wear testing processes" (PMD_0001010). No method-specific filtering needed.
→ Result: B3P = 153 · GLEX = 32 · SRV = 86 · Galling = 2 — all tribological methods via one IRI
# "One query — two methods — via international ontology standard"
PREFIX pmd: <https://w3id.org/pmd/co/>
PREFIX tc:  <https://iwm.fraunhofer.de/tribocore/ontology#>

SELECT ?method (COUNT(?exp) AS ?n_experiments) WHERE {
  ?exp a pmd:PMD_0001010 ;     # international: "wear testing process"
       tc:method ?method .
}
GROUP BY ?method
2
Scientific Question — Temperature vs. Friction
Answer a real research question from the graph: how does temperature affect the friction coefficient for Glycerol in B3P experiments? Previously: 20 minutes of manual Excel lookup. Now: one query.
→ Result live: 20°C → µ = 0.070 · 80°C → µ = 0.050
# "Scientific question answered directly from the graph"
PREFIX tc: <https://iwm.fraunhofer.de/tribocore/ontology#>

SELECT ?temperature
       (AVG(?cof) AS ?mean_friction)
       (COUNT(?exp) AS ?n)
WHERE {
  ?exp tc:method        "B3P" ;
       tc:usesLubricant
           <https://iwm.fraunhofer.de/tribocore/lubricant/Glycerol> ;
       tc:temperature   ?temperature ;
       tc:cofMean       ?cof .
}
GROUP BY ?temperature
ORDER BY ?temperature

Derivation Chain — How Was the Film Thickness Calculated?
Not just what the EHL film thickness is — but how it was derived: which viscosity (η), pressure-viscosity coefficient (α), and ball geometry were used as inputs to the Hamrock-Dowson model. Machine-readable derivation chains are required for Nature Scientific Data and reproducibility reviews.
→ Result: 48 B3P experiments with fully documented computation chain · inputs + outputs in one query
# "How was h_c computed? — provenance chain from inputs to film thickness"
PREFIX tc:   <https://iwm.fraunhofer.de/tribocore/ontology#>
PREFIX dct:  <http://purl.org/dc/terms/>
PREFIX qudt: <http://qudt.org/schema/qudt/>

SELECT ?expId ?lubricant ?viscosity_Pas ?alpha_1perPa ?filmThickness_um ?lambda
WHERE {
  ?exp  dct:identifier    ?expId ;
        tc:usesLubricant  ?lub ;
        tc:hasComputation ?comp .
  ?lub  dct:identifier    ?lubricant .
  ?comp tc:ehlInput  [ tc:property tc:viscosityAtTestTemp ;    qudt:value ?viscosity_Pas ] ;
        tc:ehlInput  [ tc:property tc:alphaPressureViscosity ; qudt:value ?alpha_1perPa ] ;
        tc:ehlOutput [ tc:property tc:filmThickness ;          qudt:value ?filmThickness_um ] ;
        tc:ehlOutput [ tc:property tc:lambdaCentralVrunIn ;    qudt:value ?lambda ] .
}
ORDER BY DESC(?filmThickness_um)
LIMIT 10

Tribology Terms

Quick reference for readers from data science, knowledge graph, or materials informatics — covering the tribological concepts that appear throughout this document.

B3P
Ball-on-Three-Plates — IWM gold-standard test. A steel ball presses under defined normal force against three stationary plates. Yields run-in CoF and Stribeck curves. Primary data basis for EHL film thickness calculations. 153 experiments integrated.
GLEX
IWM multi-temperature Stribeck test using a journal bearing geometry. One experiment runs at 3–5 discrete temperatures, each producing a Stribeck curve. Enables temperature-dependent CoF maps and lubricant viscosity crossover analysis.
Galling
Ring-on-Plate wear test (ASTM G98/G196). A rotating ring slides against a flat plate under stepwise-increasing load. Primary Kennwert: critical normal force at which adhesive wear (galling onset) initiates. Used for high-load metallic contact pairs.
SRV
Oscillating Friction and Wear Tester (DIN 51834). A ball slides reciprocally on a plate at controlled frequency and stroke. Measures CoF under oscillating conditions — relevant for seals, joints, and cam-follower contacts. 86 experiments integrated.
CoF / µ
Coefficient of Friction — dimensionless ratio of tangential force to normal force: µ = F_T / F_N. Primary output Kennwert of every tribological test. Ranges from ~0.01 (full EHL film) to >0.5 (severe boundary friction).
Stribeck Curve
Plot of CoF vs. Hersey number (η·v/p). Maps three lubrication regimes: Boundary (solid-solid contact, high µ), Mixed (partial film, µ minimum), Hydrodynamic (full film, rising µ). Shape and minimum encode lubricant–material pairing quality.
Hersey Number
Dimensionless lubrication parameter He = η·v/p, where η is dynamic viscosity [Pa·s], v is sliding velocity [m/s], and p is contact pressure [Pa]. The x-axis of every Stribeck curve. Low He → boundary regime; high He → hydrodynamic.
Abrasion (ASTM G65)
3-body rubber-wheel dry abrasion test (ASTM G65-3BA variant). A neoprene rubber wheel presses quartz sand against the test plate under 130 N load at 250 rpm for 12 minutes. Primary output: volumetric wear V (mm³) from mass loss + material density; secondary: CoF and specific removal energy SRE (J/mm³). Used to rank coating systems (HVOF WC-CoCr variants, DLC) for abrasive wear resistance. 23 Pumpen specimens integrated.
EHL / Hamrock-Dowson
Elastohydrodynamic Lubrication. At high contact pressures, lubricant film and elastic surface deformation interact. Film thickness h_c is computed from the Hamrock-Dowson (1977) equation using material moduli E*, viscosity η, and pressure-viscosity coefficient α.
