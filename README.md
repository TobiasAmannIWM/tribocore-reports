## What is TriboCore?

TriboCore KIDaT is an operational FAIR data pipeline for tribological experiments.
It connects measurement data from multiple test methods, material characterisation,
and lubricant analytics into a structured, machine-readable knowledge graph.

**Currently integrated methods (in operation since 2024):**

| Method | Geometry | Standard |
|---|---|---|
| B3P | Ball-on-Three-Plates | Anton Paar |
| GLEX | Journal Bearing (vR48) | IWM internal |
| SRV | Oscillating Ball-on-Plate | DIN 51834 |
| Galling | Ring-on-Plate | ASTM G98 / G196 |
| Abrasion | Rubber Wheel (3-body) | ASTM G65 |

**Knowledge graph infrastructure:**
- Neo4j graph database — experiment nodes linked via `HAS_COMPLEMENTARY_DATA` edges to rheology, IR spectroscopy, EIS, and Raman characterisation data
- Apache Jena Fuseki / SPARQL endpoint for federated queries
- FAIR-JSON export with SHA-256 audit trail
- Digital Product Passport (DPP) output per ESPR/GS1 schema
- openBIS specimen and lubricant registry integration

**Key figures (as of July 2026):**
- > 150 experiment nodes in the knowledge graph
- 5 tribological + 6 lubricant-analytical methods integrated
- > 1 000 cross-method `HAS_COMPLEMENTARY_DATA` edges
- Full PROV-O provenance tracing for every experiment
- PMDco / MaterialDigital ontology aligned (6/6 Hartrott points satisfied)
